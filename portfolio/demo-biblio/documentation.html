Introduction

Base URL https://api.biblio.fr/v1 · JSON partout · UTF-8. Toutes les réponses incluent le bon code HTTP. Testez chaque route dans le playground →

🔑 Authentification JWT

Après POST /login, envoyez Authorization: Bearer <token>. Token HS256, expiration 1 h (exp). Sans token → 401 Unauthorized.

Authorization: Bearer eyJhbGciOiJIUzI1NiJ9.eyJpZCI6MSwiYXQiOjE3…

POST/login

Obtenir un token. Compte démo : admin@biblio.fr / admin123

Champ Type Requis
email string oui
password string oui 
→ 200 OK
{ "token": "eyJhbGciOiJIUzI1NiJ9…", "expires_in": 3600 }

→ 401 Unauthorized
{ "error": "Identifiants invalides", "code": "BAD_CREDENTIALS" }

GET/books

Liste paginée. Auth requise.

Param Défaut Description
q — Recherche titre/auteur
dispo — 1 = disponibles only
page 1 Page (30/p, max 100) 
→ 200 OK
[
  { "id": 1, "titre": "Le Petit Prince",
    "auteur": "Antoine de Saint-Exupéry",
    "annee": 1943, "dispo": true }
]

POST/books · admin

Créer un livre. Titre + auteur requis.

→ 201 Created
{ "id": 42, "titre": "Dune", "auteur": "Frank Herbert",
  "annee": 1965, "dispo": true }

→ 422 Unprocessable Entity
{ "error": "Validation échouée",
  "fields": { "titre": "requis" } }

POST/loans

Emprunter un livre (transaction atomique).

Body: { "book_id": 2 }

→ 201 Created
{ "success": "emprunt enregistré",
  "book": { "id": 2, "dispo": false } }

→ 409 Conflict
{ "error": "Livre déjà emprunté", "code": "BOOK_UNAVAILABLE" }

DELETE/loans/{id}

Rendre un livre. Remet dispo = true.

→ 200 OK
{ "success": "retour enregistré", "book_id": 2 }

→ 404 Not Found
{ "error": "Emprunt introuvable" }

⚠️ Codes d'erreur

HTTP Signification
400 Requête malformée
401 Token manquant / invalide / expiré
403 Droits insuffisants (admin requis)
404 Ressource introuvable
409 Conflit (déjà emprunté)
422 Validation échouée (détail par champ)

Format unique : { "error": "…", "code": "…" }
