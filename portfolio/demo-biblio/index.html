Endpoints principaux

Une URL prévisible par ressource. Le détail complet est dans la documentation.

POST/login

Échange email + mot de passe contre un JWT valide 1 h.

GET/books?q=&page=

Liste paginée du catalogue, recherche plein texte.

POST/books

Ajout d'un livre (admin). Validation stricte, 201 Created.

POST/loans

Emprunter : transaction atomique, 409 si indisponible.

DELETE/loans/{id}

Retour de livre, stock remis à disponible.

GET/me/loans

Historique des emprunts de l'utilisateur connecté.

Démarrage en 3 étapes

De zéro à votre premier appel authentifié.

1 · LOGIN

POST /login avec admin@biblio.fr / admin123 → recevez un token JWT.

2 · AUTHORIZE

Ajoutez Authorization: Bearer <token> à chaque requête.

3 · CALL

GET /books, POST /loans… réponses JSON + bons codes HTTP.

curl -X POST https://api.biblio.fr/v1/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@biblio.fr","password":"admin123"}'

# → { "token": "eyJhbGciOiJIUzI1NiJ9…" }

curl https://api.biblio.fr/v1/books \
  -H "Authorization: Bearer VOTRE_TOKEN"
